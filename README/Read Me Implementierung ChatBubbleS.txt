3. Inspector Setup

Name Input → NameInput

4. Verhalten

• Name wird automatisch von LoginScript übernommen
• Passwortfelder sind maskiert
• RegisterButton wird nur aktiv wenn alle Felder gefüllt
• Nach loadingTime verschwindet LoadingScreen
